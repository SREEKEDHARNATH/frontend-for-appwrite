# frontend.

A modern, responsive React landing page built with Vite and Tailwind CSS.

## Features

- Hero-focused home page with gradient visuals and smooth animation
- Reusable UI components (buttons, cards, contact form)
- Responsive, mobile-first layout
- Sticky header navigation and footer
- Optional dark mode toggle with local preference persistence
- SEO-friendly metadata and semantic HTML

## Tech Stack

- React
- Vite
- Tailwind CSS

## Scripts

- `npm run dev` - start development server
- `npm run build` - production build
- `npm run preview` - preview production build locally
- `npm run lint` - run oxlint
